Sesión de Codespaces

Usa un fine-grained personal access token limitado al repositorio privado del asistente. El token se guarda solo en sessionStorage y nunca se envía al sitio de GitHub Pages.

Permisos mínimos recomendados

Limita el token al repositorio privado del asistente y concede únicamente Codespaces: Read and write y Codespaces lifecycle admin: Read and write. El permiso de Codespaces con escritura se usa únicamente para crear el entorno administrado. No se necesitan permisos de Contents, Issues, Pull requests ni Actions.

Frontera de privacidad

Este sitio público administra únicamente el ciclo de vida del Codespace. No contiene, consulta ni almacena CVs, vacantes, aplicaciones, tracker, documentos ni datos del candidato. Esos datos permanecen en el Codespace privado.
